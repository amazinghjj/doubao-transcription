# 听写工作台

基于火山引擎「录音文件识别 2.0」的本地网页转写工具。支持 Linux 和 macOS，使用自己的豆包语音 API Key，将录音转换为可编辑文字和字幕。

网页和配置管理在本机运行，录音识别由火山云端完成，需要联网。

## 功能

- 选择本地录音，或粘贴音频下载直链。
- 支持 MP3、WAV、OGG；M4A、AAC 使用 FFmpeg 转换后上传。
- 自动标点、数字规范化，可选说话人区分和去除口头语。
- 编辑、复制文字，下载 TXT、SRT、时间戳文本和原始 JSON。
- 本地保存任务历史，重新查看结果、保存修改、继续查询未完成任务。
- 保存 API Key 和 TOS 配置，下次自动读取；敏感字段默认遮挡，可切换显示及修改。

## 快速开始

### 1. 准备环境

- Linux 或 macOS。
- Python 3.10+，包含 venv、pip；Bash。
- 处理 M4A/AAC 时需要 PATH 中可执行的 FFmpeg。
- 已开通火山引擎录音文件识别 2.0，具有可用 API Key 和额度。

使用本地文件还需要 TOS 私有存储桶及 AK/SK；已有可访问音频直链时无需配置 TOS。

### 2. 启动

如果从 GitHub 克隆源码，需先安装 Node.js 22.13+，在项目目录构建网页（发布源码不包含 dist）：

```bash
npm ci
npm run build
```

使用已包含 dist/client 的通用部署包可跳过此步。

在本项目目录执行：

```bash
bash start.sh
```

首次运行会创建独立的 `.venv` 并安装 Python 依赖。启动后访问：

**http://127.0.0.1:8765**

保持终端运行，按 `Ctrl+C` 停止服务。通用部署包已包含编译后的网页，日常运行不需要 Node.js。

### 3. 配置并转写

1. 在网页填写 API Key；使用本地文件时再填写 TOS 配置。
2. 点击“保存 / 更新配置”。
3. 选择录音或填写直链，点击“开始转写”。
4. 完成后编辑、下载文字，或在页面下方查看历史记录。

建议首次使用短录音验证账户权限。提交超时后先使用原任务编号继续查询，避免重复提交。

## 项目结构

```text
录音转文字/
├── app/                     网页主页面、布局和样式源码
├── components/              界面组件
├── hooks/、lib/              前端辅助代码
├── public/                  静态资源和操作说明源码
├── local-server/            Python 后端源码与依赖清单
├── dist/client/             编译后的网页，运行时使用
├── dist/server/             构建辅助产物，本地部署不使用
├── data/                    个人配置和历史，不随安装包发布
├── start.sh                 通用启动入口
├── package.json             前端依赖与构建脚本
├── package-lock.json        前端依赖锁文件
└── *.md                     项目文档
```

源码和编译产物位于同一项目根目录的不同子目录。不要直接修改 `dist/`，下次构建会覆盖它。

## 开发入口

用 IDE 打开本目录。修改网页需要 Node.js 22.13+：

```bash
npm ci
./node_modules/.bin/tsc --noEmit
npm run build
bash start.sh
```

修改前端后重新构建并刷新页面；修改 Python 后端后重启服务。

**运行入口是 `bash start.sh`。** 当前 `npm start` 仍为脚手架的托管工具命令，不适用于本地部署。`npm run dev` 的跨端口请求也尚未与后端来源校验整合；完整功能调试使用构建后访问 Flask 的流程。详情见开发维护文档。

如果更改了 Python 依赖，显式更新环境：

```bash
.venv/bin/python -m pip install -r local-server/requirements.txt
```

## 配置与数据

| 内容 | 默认位置 / 参数 |
|---|---|
| API Key、TOS 配置 | `data/config.json` |
| 历史任务与文字 | `data/history/` |
| 自定义数据目录 | `ASR_DATA_DIR` |
| 服务端口 | `ASR_PORT`，默认 `8765` |
| 可选自动打开浏览器 | `ASR_OPEN_BROWSER=1` |

配置为明文 JSON，写入权限为 `600`。空密钥表示保留已有值，不会删除已保存密钥。配置接口会向本机网页返回当前值，以供显示和编辑。

迁移时另行备份 `data/`，不要跨系统复制 `.venv/` 或 `node_modules/`；在目标系统重建依赖。安装包排除个人配置、历史、录音和依赖环境。

## 运行边界

- 服务默认仅监听 `127.0.0.1`，没有公网账户登录功能。远程服务器可通过 SSH 隧道访问，见部署指南。
- 语音识别与 TOS 存储、访问可能产生费用，以火山账户当前规则为准。
- 云端录音保留在用户自己的 TOS 中，需自行设置生命周期；工具不会自动删除。
- 暂停本地查询不会取消云端识别任务。
- 已完成本地功能测试与构建检查；尚未在实际 Linux 主机上执行端到端验证。
- 当前发布包包含源码与运行所需的编译产物，未拆成独立的源码包和纯运行包。

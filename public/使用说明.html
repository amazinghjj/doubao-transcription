首次使用与配置

这个网页运行在你的电脑上。录音识别由火山引擎录音文件识别 2.0 完成，需要联网；这不是离线模型。

一、启动

推荐 Docker Compose：在项目目录执行 docker compose up -d --build，访问 http://服务设备IP:8765。无需在宿主机安装 Python、Node.js 或 FFmpeg。配置和历史保存在 Docker 数据卷，容器重建后保留；不要使用 docker compose down -v，它会删除数据卷。原生 data 目录不会自动导入，迁移方法见部署指南。

Linux 和 macOS 均使用相同入口。在工具目录中执行 bash start.sh。需要 Python 3.10+、venv 和 pip；M4A/AAC 转换需要 PATH 中可用的 FFmpeg。首次运行会创建独立环境并安装依赖，日常运行不需要 Node.js。

访问 http://127.0.0.1:8765。终端按 Ctrl+C 停止服务。详细说明见安装包内“部署指南.md”。

局域网访问

在服务设备执行 bash start.sh，其他设备访问 http://服务设备的局域网IP:8765。配置与历史保存在服务设备，所有访问者共享，并可查看密钥和提交计费任务。此模式没有登录且 HTTP 不加密，仅用于可信内网。请检查防火墙允许内网访问服务端口；不要开启公网端口转发。更换启动模式前先停止旧服务。

二、准备豆包语音 API Key

  1. 进入 豆包语音新版控制台，确认已经开通“录音文件识别 2.0”，并有可用额度或余额。
  2. 在 API Key 管理中获取密钥，填入工作台顶部。不要使用其他产品的密钥代替。

工具固定调用 volc.seedasr.auc，不自动切换其他模型。配置通过“保存 / 更新配置”按钮写入本地 data/config.json 文件，开始转写时也会保存。下次打开自动使用已保存配置；配置框会回填当前保存的值。Access Key ID 明文显示，API Key 与 Secret Key 默认用圆点遮挡，点击右侧小眼睛可切换明文显示。修改时填写新值再保存，密钥框留空表示保留原值。配置文件为明文，默认仅当前系统用户可读写（600 权限）。任务编号会保留在浏览器本地，用于恢复查询。

三、本地录音：开通 TOS

标准版 2.0 要求音频下载链接。工具会把你选择的本地文件上传到你自己的私有 TOS 存储桶，生成有效期为 24 小时的签名下载链接，交给语音服务读取。

  1. 登录火山引擎控制台，进入 对象存储 TOS，按页面提示开通服务。
  2. 创建专门存放录音的存储桶。选择所需地域，例如华北 2（北京）；访问权限保持私有。记录存储桶名称，以及对应地域代码（北京为 cn-beijing）。其他地域请从存储桶概览查实际代码，不要填写城市中文名。
  3. 在访问控制 IAM 中为此用途创建子用户及访问密钥，得到 Access Key ID（AK） 与 Secret Access Key（SK）。这是一对 TOS 访问凭证，和豆包语音 API Key 不同。
  4. 给该用户授予目标桶 local-asr/ 前缀的对象上传、读取，以及设置私有对象 ACL 所需权限（PutObject / GetObject / PutObjectAcl；具体策略动作及资源写法以当前控制台为准）。本工具不需要列出全部桶，也不需要管理其他云资源。若权限报错，检查桶策略是否另有显式拒绝。
  5. 在工作台展开“TOS 上传配置”，填入桶名、地域、AK、SK。
  6. 建议在桶的生命周期规则中，为 local-asr/ 前缀设置 3 天后过期清理。若希望长期保存录音，按实际需求延长。工具不会自动删除云端对象；多版本桶的历史版本也要另设清理规则。

录音文件始终以私有对象上传，不需要将桶改成公开，也不需要配置浏览器跨域规则。TOS 存储、访问流量和语音识别可能分别计费，以控制台显示为准。

四、转写与导出

  1. 先选择 30～60 秒录音测试。支持 MP3、WAV、OGG；M4A、AAC 会在 本机转换为 WAV 后上传。文件及转换结果应小于 500 MB；超长音频建议先分段，并遵守云服务当前时长限制。
  2. 可选“区分说话人”。需要尽量保留原话时，不勾选“去除口头语与重复表达”。
  3. 点击“开始转写”，依次等待上传、提交、排队、识别。请保持网页和本地服务运行。
  4. 完成后可编辑文字、复制，或下载 TXT、SRT、时间戳文本和原始 JSON。TXT 使用你编辑后的文字；其他格式使用原始识别分句。说话人编号是模型聚类结果，不是真实姓名，混音或重叠说话时可能不准确。

已有音频链接

切换“音频链接”，粘贴服务器可以直接下载的 HTTP/HTTPS 文件地址，并选择实际格式（MP3、WAV、OGG）。这种方式无需配置 TOS。网盘分享页、本地路径和只在你电脑上可访问的地址都不能使用；临时链接需在识别服务读取时仍有效。

历史记录

新提交的任务及识别结果自动保存在此工具文件夹内的 data/history 中。下次打开页面，可在底部历史记录列表中查看。已完成记录可直接阅读和下载；未完成任务使用已保存的 API Key 继续查询。文字编辑后点击“保存修改”，切换历史记录前也会保存当前修改。历史不保存密钥、音频下载链接或录音文件。迁移时请自行保留 data 文件夹；安装包不包含个人历史。旧版本未保存的历史不能自动补回，但保留了任务编号的录音可以尝试继续查询，成功后会存入历史。

中断与恢复

网络断开或关闭页面后，云端任务可能还在继续。重新打开页面，使用已保存的同一个账户 API Key，确认原任务编号，点击“继续查询”。提交超时不等于提交失败，先查询，避免再次上传和重复计费。“暂停”只停止本地轮询，不取消云端识别。默认连续查询最多 4 小时，到时可手动继续。

常见问题

情况处理
TOS 上传失败核对桶名、地域、AK/SK、上传/读取/设置 ACL 权限和网络连接。
识别调用失败检查 2.0 是否开通、API Key 是否来自豆包语音、额度/余额、音频直链是否过期。错误中的状态码和日志编号可提供给火山客服，勿附密钥。
音频转换失败先在音频软件中导出为 MP3 或 WAV 后再选择。
一直排队继续查询当前任务，不要反复提交。
页面打不开重新执行 bash start.sh，检查终端提示，确认端口 8765 未被其他程序占用。
